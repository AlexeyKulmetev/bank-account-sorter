📌 Описание

Учебный проект, реализующий решение классической алгоритмической задачи:
обработка списка банковских счетов с последующей сортировкой и подсчётом повторений.

## Функциональность

- **Циклическое меню** с выбором действий.
- **Ввод данных** тремя способами:
  - случайная генерация;
  - ручной ввод с консоли;
  - чтение из файла (формат: `номер,владелец,баланс`).
- **Просмотр текущих данных**.
- **Сортировка** по:
  - номеру счета (лексикографически);
  - имени владельца;
  - балансу (числовое сравнение);
  - *специальная сортировка*: только элементы с **чётным** балансом сортируются по возрастанию, нечётные остаются на своих местах.
- **Сохранение** коллекции в файл в режиме добавления (append).
- **Многопоточный поиск** количества счетов с заданным балансом (сравнение с допуском 0.001).
- Валидация данных при создании объектов (номер ≥5 символов, имя не пустое, баланс ≥0).


🛠️ Используемые технологии

- Java (версия 8+)
- Собственная реализация коллекции `CustomArrayList<T>` (на основе массива)
- Паттерны: **Стратегия** (ввод, сортировка), **Строитель** (Builder)
- Стримы для заполнения коллекций
- Многопоточность (два потока для поиска)
- Ручные тесты (без внешних библиотек)


🚀 Как запустить

Клонировать репозиторий:

git clone https://github.com/AlexeyKulmetev/bank-account-sorter.git

Перейти в папку проекта:

cd bank-account-sorter

Скомпилировать и запустить:

javac Main.java

java Main

Примечание: для корректной работы файлового ввода/вывода необходимо указывать абсолютный или относительный путь к файлу (например, input.txt).

Использование
В главном меню выберите пункт 1 для заполнения коллекции.

Укажите способ ввода (1 – случайный, 2 – ручной, 3 – из файла) и количество счетов.

После загрузки данных выберите 2 для просмотра.

Для сортировки используйте 3 и выберите критерий.

Сохраните результат в файл (пункт 4).

Выполните многопоточный поиск по балансу (пункт 5).

Выход – 0.
